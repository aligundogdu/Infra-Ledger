Infra Ledger

Credentials with a paper trail.

Visual identity and voice for the Obsidian plugin that keeps server, database and cloud details in your notes, and records every password change with its date and reason.

01

Idea

A ledger never erases an entry. The line is struck through and the new one goes below it. Infra Ledger keeps passwords the same way: the old value doesn't disappear, it moves into history with its date.

  1. Bars: rack units and ledger linesThe top bar is full color, the current entry. The bars below fade into history. The opacity order (100 / 50 / 22) never changes.
  2. Red vertical line: the ledger marginIt separates the entry from the note. In the UI the same line means "this password changed".
  3. Green dot: the server status LEDThis entry is current. It is the only bright spot in the logo.

06

Voice and tone

Like a note from one person who runs servers to another. Short, factual, says what happened.

  1. Say what happened, not how it feels."Password changed. Previous value moved to history." No exclamation marks, no "Success".
  2. Use numbers and names."Clipboard clears in 30 s." "Duplicate id forge-key in HomeServer.md and Forge.md."
  3. Don't oversell security.Say plainly what the plugin doesn't protect. If encryption is off, show it.
  4. Error messages state the next step."Can't save: YAML error on line 4. Fix it in source mode, then try again."
  5. Don't blame the user."This block has a YAML error...", not "You entered an invalid...".

Words

Use

  • credentials, resource, history, rotate
  • plain Markdown, readable without the plugin
  • optional encryption
  • copy, search, change password

Avoid

  • military-grade, bank-level, unhackable
  • 100% secure, zero risk
  • powerful, seamless, effortless, robust
  • leverage, streamline, supercharge
  • "password manager" (to describe itself)

Honest security statement

Infra Ledger stores everything in your vault as plain Markdown. If your vault syncs to iCloud, Dropbox or Git, your credentials go with it. Optional encryption protects the secret fields with a master password. Hostnames, users and notes stay readable so you can search them.
